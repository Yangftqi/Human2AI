# Human2AI：主流大模型“AI八股”与社区热梗提示词库

## 核心设计亮点

1. **「输入长度 × 模型本性」动态篇幅自适应**：彻底取消死板的固定字数下限与上限！例如输入一句简短的 `“我同意你的看法”`，**DeepSeek** 会冷酷压缩成四字硬汉绝杀 `“这句，我认。”`，而 **Gemini** 则会顺应其酒馆戏精本性当场演出攥白指节、仰倒椅背、长剑劈开迷雾的一长串华丽咏叹调。
2. **反串味互斥锁与纯净混沌美学**：各家提示词互不侵犯，且混沌版专门移除了市井顺口溜画风的 Grok，仅融合 **Gemini × GPT × Claude × DeepSeek** 四大“衣冠楚楚装腔系”八股，维持纯粹而高级的赛博精神分裂感。
